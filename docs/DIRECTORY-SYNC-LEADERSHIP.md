# 当前通讯录同步与主管、组长权限

本轮仅面向隔离测试环境。公司主体、法定代表人与部门协作继续分别维护，生产部署和钉钉源目录不修改。

## 当前与历史资料

手动“同步通讯录”读取当前目录各页和每个成员详情，校验稳定身份、部门树及目标组织，完成读取后才写入。分页不完整、空成员目录、详情错误、重复游标、跨主体冲突时保留原数据。结果包含当前人数、新增/更新人数与保留历史档案数。

当前源目录快照仅投影展示。未出现的已存在档案保留原部门挂靠、账号、就业事实及存储授权，不据此判断离职、删除或批量停用；管理员可展开历史档案核验。公司字段单独刷新不覆盖已完成的成员快照。

## 经确认的负责人层级

由服务器的 `dingtalk_leadership_policy` 保存指定组织、确切部门代码和已确认类型，不凭树深度、名称后缀或浏览器提交的角色授予权限。当前按用户口径核对：12个中心/职能单位、11个小组；公司名节点不授予部门主管身份。

- 中心/职能部门：钉钉主管标记映射为 `department_manager`，范围为本部门及同一组织的下级。
- 小组：标记映射为 `group_leader`，范围仅本组，不继承子节点、上级或其他组；保留基本资产维护与组织查看，不能维护全局配置或获得部门主管的流程维护权限。
- 未分类的来源节点：不自动授予主管权限；页面显示负责人待核验。
- 采购一组陈先彬（钉钉名夏天-陈先彬）归为组长。客户运营的负责人岗位为客服组长，因此该子单位也归为小组；客户运营部仍为职能单位。

已有系统管理员和目录外人工授权保留。对当前已核对钉钉成员，来源单位的有效主管身份由最新挂靠及明确类型计算，原存储角色保留用于审计/回退；历史档案不因目录缺席收缩权限。测试环境取消全量操作绕过，实际RBAC与正式工程一致。

## 实时同步评估

当前工程只有手动拉取，尚未接入事件订阅。钉钉官方支持成员和部门变更事件；可以采用可信事件接收、校验、幂等增量处理和失败重试，并用周期性全量核对补漏。还需核实应用通讯录可见范围、事件配置、来源身份、运行资源和回退策略，本轮未启用订阅或新增应用权限。

官方依据：[钉钉企业内部应用通讯录同步](https://help.aliyun.com/zh/idaas/eiam/user-guide/binding-dingtalk-party-applications)、[钉钉成员全量与增量同步说明](https://help.aliyun.com/zh/agentidentity/configure-dingtalk-as-the-identity-provider-for-the-user-pool)。引用的是钉钉事件能力，不意味着本工程接入或需要新增IDaaS产品。

## 验证和回退

本地仅使用127.0.0.1:55433的独立演练库。定向验证同步完整性、身份/跨组织守卫、历史资料不变、组长仅本组、部门主管同组织下级、私人资料隔离、管理员/开发控制面及钉钉会话兼容。前端验证类型、构建、当前/历史成员投影及公司/部门分离。

测试发布前校验既有后端哈希、当前测试前端版本、服务环境和Schema，备份受影响源码及测试库，冻结明确代码/构建清单，保留生产基线。代码回退优先恢复原源码和前端，保留同步事实；数据恢复需核对操作后指纹未漂移，不能覆盖后续业务。服务器与真实页面结果记录在部署交付与任务记录中，自动验证不代替真实组长/主管登录业务UAT。

# 资产中心统一设计规范

2026-10-09。UI/UX Studio 制定，用户确认：白色侧栏、荧黄选中态；界面统一使用“资产”，资产库按实际分类设置页签。本规范取代旧主题说明，当前实现已按用户授权发布，见 [实现与发布记录](ASSET-CENTER-FRAMEWORK-20261009.md)；真实业务验收分别记录。

## 用户与任务

- 员工：登记 AI 成果、查找可用成果、维护自己负责的资料、提交使用申请。
- 管理人员：查询公司资产，维护责任与关联，审核成果，处理到期事项和申请。
- 系统管理员：管理分类、组织同步、连接器与审计。

全局侧栏保持员工任务与管理入口分组。管理页面共享二级导航；已有角色限制继续生效，入口显隐不能代替服务端授权。

## 视觉基础

唯一前端主题 ID：`asset-center`，实现入口 `frontend/src/styles/tokens.css`。不提供历史主题切换。

| 用途 | 规范 |
| --- | --- |
| 侧栏、内容卡片 | 白色 `#ffffff` |
| 工作背景 | 浅灰 `#f6f7f6` |
| 选中侧栏 | 荧黄 `#e7ff3f`，深色文字 |
| 文字 / 次要文字 | `#151a17` / `#677164` |
| 边框 | `#e2e7e0` |
| 键盘焦点 | `#526c2b`，2px 外框 |
| 危险操作 | `#a92a22`，同时显示动作文字 |
| 字体 | Inter、系统中文字体；正文 14px，辅助文字 12–13px |
| 间距 | 8 / 16 / 24 / 32px |
| 圆角 | 容器 12px，控件 8–9px |
| 常用控件 | 最小高度 40px；长名称允许换行 |

保留现有 FlipBelt 标志。状态、错误、权限与成功信息不能只用颜色区分。阴影仅用于必要的浮层，不使用装饰性渐变或复杂仪表盘。

## 页面框架

登录使用独立布局，收起业务导航与搜索；钉钉扫码为主要入口，已授权系统账号折叠为次要入口。加载、超时与异常恢复采用同一白灰底色、深色文字与荧黄强调。网站图标使用层叠资产几何符号，保留原 FlipBelt 完整标志。头像只读取当前已认证会话返回的本人头像地址；缺失或加载失败显示姓名首字，头像不作为权限或公司归属依据。具体实现与验证见 [登录与身份界面记录](LOGIN-IDENTITY-DESIGN-20261009.md)。

页面按标题与主要动作、上下文导航或视图选择、筛选、数据、分页组织。一个页面只有一个主标题；主要操作使用深色按钮及荧黄文字。说明只解释当前任务，不重复介绍系统结构。

管理概览按“资产与资料”“审核与跟进”组织真实入口。系统设置是独立导航项。登记入口按公司、平台、企业账号、登录身份、资源、供应商、人员授权等业务名称选择；不要求用户理解内部层级编号。

环境入口仅在系统管理员的“系统设置 → 环境管理”页签展示。顶部和侧栏不显示环境切换或环境标签；常规站点称为“资产中心”，测试侧返回入口称为“返回资产中心”。测试侧登录页保留测试标识，页面文案、提示与可访问标签均避免“生产环境”用语。界面显隐沿用现有角色控制，不改变服务端 RBAC、会话隔离或已有地址的访问权限。

## 资产库

- 默认是业务资产清单；来源资料通过辅助视图进入。平台、公司账号、子账号、注册身份及个人订阅在“平台与账号”维护，资产清单、计数、导出和管理概览在服务端排除这些记录。个人订阅免审及可见权限保持，旧“我的订阅”入口转到平台入口并保留个人账号页签。
- 分类页签由 `asset-categories` 的实际分类与顺序生成，含“全部资产”，不再显示“平台与账号”分类。分类 ID 保存在网址，返回和前进可恢复选择。
- 分类精确匹配 `AssetType.category_id`，不隐含扩大到下级分类。每一实际分类均可单独查看，包括空分类。
- 类型、部门、状态与搜索条件在服务端组合筛选。页签不展示当前页推算的分类总数；结果总数来自服务端分页响应。
- 分类切换重置类型和分页，保留搜索、部门与状态。回收站沿用分类；权限、版本确认与恢复流程不变。
- 表格主要列：资产名称与编号、类型、归属、状态、到期、允许的操作。长名称换行；更新与完整责任资料在详情查看。
- 表头、查询输入和分类页签具有可访问名称；页签支持方向键、Home/End；加载、失败重试、空列表和无匹配结果分别呈现。

## 表单与状态

先呈现核心资料，选填信息放在可展开区域。业务对象名称、填写提示与实际字段一致。切换登记类型同步网址；返回选择页恢复键盘焦点。成功回执区明确保存对象、关联及后续动作。

保存时禁用重复提交；失败保留已填数据并显示错误。删除保留现有确认弹窗和确切资料修订；界面重构不执行真实资产审核、指派、删除或恢复。

## 平台账号与员工交接

- “平台与账号”一级页按平台/供应商展示；进入平台后分公司账号、个人账号、待核验/待交接、注册身份和资料与套餐，再进入父账号维护子账号。子账号不作为资产或跟进的独立列表项。
- 子账号可选择所属公司的在职员工，带入姓名/邮箱并允许按实际登录标识修改。员工绑定记录使用与交接关系，实际平台权限须单独核对；服务账号允许无员工绑定。
- 到期与责任采用已确认、有效期内的在职责任人；部门归属不等于负责人。子账号的未绑定/离职事项汇总在所属父账号，点击进入对应层级。
- “组织与授权 → 离职员工”分在职/待核实、已离职、离职待交接。离职登记需日期、依据和明确操作，停用本系统登录并保留账号、责任、授权历史。源资料缺失不能推断离职；纠正状态不自动恢复登录或授权。
- 新弹窗使用既有焦点限制与 Escape 关闭；页签支持方向键/Home/End，空、读取错误、保存错误和只读权限分别呈现。

## 响应式与兼容

宽屏使用固定白色侧栏和流式内容，管理内容最大 1440px；各管理标签页正文占满同一内容容器，与资产库保持相同左右边界，不随文字或空状态收窄。此规则同时覆盖嵌套的系统设置页及全部子页签、导入上传/粘贴区和下方示例区，不能仅检查页面外层。列表与资料卡片的方形图标容器水平、垂直居中，文字样式不得覆盖图标容器的布局或边距。中屏筛选分行；窄屏表单改单列，页面动作换行，分类导航与宽表格在各自区域滚动，整页不横向溢出。遵循减少动态效果偏好。

退役页面删除前端实现，旧链接定向到当前资产、导入或跟进页，资产详情保留原 UUID。后端聚合接口仍服务于当前详情和审核，不能因名称历史而删除。

## 验证要求

验证导航角色、网址状态同步、分类与分页组合、删除恢复负向路径、构建与旧链接。渲染检查覆盖资产库桌面与窄屏、管理概览、登记表单和外观说明。

本地合成数据只证明布局与交互；不代替生产登录、真实数据或人工业务验收。发布必须绑定已审阅候选版本的明确授权。

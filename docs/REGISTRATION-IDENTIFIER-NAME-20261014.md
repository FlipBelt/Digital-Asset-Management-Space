# 注册与登录标识：标识即名称

用户于 2026-10-14 要求“名称和标识，仅保留标识作为主键，标识即为名称”。本次取消独立名称的业务概念，标识值为唯一业务标识和显示名称。技术 UUID、短编号和关联外键继续保留，避免更正标识破坏平台引用。

## 行为

- 列表、回收站只展示一次标识值，类型为辅助信息；删除独立“修改名称”按钮，统一在“修改资料”更正标识和维护其他资料。
- 注册标识响应的 `name` 保留为兼容展示字段，始终取自 `identifier_value`。平台账号上下文、登记回执、资产详情和关系节点按同一源显示。
- 新建、更正和批量更新不接受独立别名。旧 `/name` 入口标记废弃并返回 422，说明使用“修改资料”；通用资产编辑同样拒绝另写标识名称。
- 标识继续按既有指纹查重；完整归档无有效引用的历史键只在用户提交对应更正时按既有规则释放。来源仍选填，权限、版本、引用保护和可恢复删除保持。
- `identifier_value` 保留完整 500 字符。旧 `Asset.name` 的 200 字符列仅为兼容缓存；所有相关当前读取投影从完整标识取名。读取旧名称不会写数据库或批量迁移。

# 注册与登录标识：更正原标识内容

日期：2026-10-14。用户反馈已有标识的手机号/邮箱只读。本次业务修改为 T2；部署按 T3 验证。Schema f13f20261010 保持，无迁移。

## 行为

- 平台与账号 → 注册与登录标识 → 修改资料允许更正手机号、邮箱、用户名、微信及其他账号标识；类型可选择，输入只在保存中临时禁用。
- 修改按原 asset_id 保存；资料 UUID、简短编号和平台账号引用保留，不按更正后的值新增记录。外部平台的真实登录资料不会被改写。
- 手机号统一去掉国家前缀、空格及连接符；邮箱忽略大小写。已有有效记录或回收站记录占用相同标识时返回 409 并列出冲突编号及查看入口，格式错误返回 422，版本过期或改变幂等请求内容返回 409。
- 系统/资产管理员沿用现有管理范围；普通员工及缺少 CSRF 的 Cookie 写请求被拒绝。核对资料来源为选填，允许空白或省略；仍保留操作人、时间与幂等审计，不声明短信或邮箱验证。
- 自动生成的名称随更正同步；单独设置的显示名称保留。历史资料未登记公司或保管人时可更正标识，不创建空责任记录，不改写既有责任。
- 新增/批量手机号与邮箱登记仍按值核对；用户名等标识的修改入口不再受手机号/邮箱识别条件限制。

- 已完全归档且没有有效平台账号或资产引用的历史档案不再占用当前更正的唯一查找键。只调整归档档案的查找键，原标识、UUID、编号、内容和归档状态保留，并记录审计；有效、回收站、部分归档和仍有引用的历史档案继续保护。过期版本或校验失败会回滚整个事务。
- 表单控件靠上对齐，避免公司和部门下拉框随人员选择器被撑高。

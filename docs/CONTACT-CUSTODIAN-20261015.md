# 通讯资源保管同事与归属公司校验一致性

关联任务：[FBC-183](https://linear.app/j21nianyi/issue/FBC-183)。代码：[PR #19](https://github.com/FlipBelt/Digital-Asset-Management-Space/pull/19)。

## 问题与规则

手机号、邮箱的归属公司与共享通讯录中的人员公司 ID 可能不同。原表单按公司 ID 过滤保管同事，服务端也无条件要求同公司，导致管理员无法登记实际保管人。

- system_admin / asset_manager 可跨公司指定在职、未归档的保管同事及有效使用部门；非全局管理员仍受原公司边界限制。
- 新增、修改、批量核对和旧登记入口共用保管人校验。保留通讯资源原有在职联系人类型口径，不额外限制为 employee。
- 表单候选、使用部门和批量预览采用一致规则；批量资料保持所选标识归属公司，同名候选优先匹配同公司，歧义继续阻止保存。
- 保管同事与标识归属公司分别维护，不更改人员归属。原编号、平台引用、版本冲突、幂等、审计及批次原子性保留。

修改范围：backend/app/api/v1/workspace.py、backend/app/services/contact_resources.py、ContactResourcesPanel.vue、contactRegistration.ts、IntakePage.vue，以及对应后端测试和前端断言脚本。

# 子账号继承与卡片访问链接

2026-10-12。用户要求子账号免审、免核验、不显示首页、信息沿用父账号；自研系统及其他资产卡片提供已有链接并保持对齐。沿用本线程发布授权，实际账号核验与员工资料仍由业务人员确认。

## 实现

- 根据真实 Account → PlatformTenant 关系识别子账号，不依赖客户端填写的来源或资产类型。新子账号免审；旧记录读取时同样免审，无历史批量改写。
- 个人空间在计数、分组和分页前排除子账号。旧 `/assets/:id` 与 `/discover/:id` 进入所属父账号；归属、责任、状态、到期和核验状态动态读取父账号，保留子账号 UUID、修订、登录信息、员工绑定与交接历史。
- 阻止子账号独立修改治理信息、草稿确认或进入 AI 审核队列；读取父账号资料必须通过其原有可见权限。
- 卡片从系统接管资料、资源管理地址、普通 URL 字段、说明内 Markdown/裸链接及来源引用提取链接，去重并限制 http/https。密码库引用和限制级自定义字段不进入卡片。
- 链接按钮统一 40px，责任与操作区置于底部；说明最多四行摘要，完整内容保留在详情。沿用现有荧黄/白灰主题、键盘焦点与响应式布局。

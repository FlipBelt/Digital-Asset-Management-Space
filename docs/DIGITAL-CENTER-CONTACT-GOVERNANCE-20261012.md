# 数字中心：通讯资源与账号治理

日期：2026-10-12。状态：实现与本地回归完成，待本轮测试发布、正式发布及资料登记回读。

用户已授权本任务发布，并确认整个平台产品名为“数字中心”。外部平台名称与“平台与账号”导航保留。

- “平台与账号”一级入口增加“手机号与邮箱”。号码/邮箱先登记实际保管同事或共用部门，具体平台账号再引用；历史平台注册用途不自动绑定账号。
- 管理员可按来源资料批量预览、登记或更新。保留原 UUID，使用修订校验、请求幂等及审计。资料核对状态不代表短信/邮箱或运营商实名核验。标注禁止注册的资源不能被账号引用。
- 平台账号 ID 只填写一次，类型改为选项；来源说明单独填写。重复平台、公司、原生 ID 会拦截，集团管理员可登记跨公司通讯资源引用与协同责任，但不自动改写归属、指派负责人或授予权限。
- 关系入口采用“依赖与归属”“引用与使用”“协作与同级关系”，展示具体关系方向；注册所用手机号/邮箱与人员责任分开。
- 公司资产列表排除已明确标记的历史平台目录服务记录，原记录与关系在平台管理中保留；实际 API 实例仍归入资产库。正式资料整理仅处理用户截图确认的五项，保留来源和操作审计。
- 使用申请引用已有公共平台或可见企业账号；名称由服务端生成，无需手填。申请本身不分配席位、不创建账号、不授予权限。
- 卡片按用途显示“GitHub”“部署说明”“恢复说明”等链接。负责人/管理员填写仓库公开、私有或尚未确认；私有/未确认时隐藏 GitHub 地址和按钮，包含卡片、详情、字段、列表及导出读取。已保存原始地址保留，应用入口继续展示。

沿用现有数据库模型，无 Schema 迁移；仓库可见性与注册限制使用已有资产标识，通讯资源仍是独立资产。代码发布与业务资料更新分开验证，均可回滚。

本地验证：相关业务、权限和生命周期用例分批回归；前端类型检查与构建；链接安全与隐私 21 项断言；通讯资源解析 14 项断言。完整运行结果和正式发布回执在本轮交付后补记，人工业务验收待用户确认。

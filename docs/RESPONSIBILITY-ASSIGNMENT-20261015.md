# 责任人员选择与保存校验一致性

关联任务：[FBC-174](https://linear.app/j21nianyi/issue/FBC-174)。代码：[PR #14](https://github.com/FlipBelt/Digital-Asset-Management-Space/pull/14)。

## 问题与规则

企业账号登记允许全局管理员指定跨公司协同员工，详情确认却无条件比较人员和资产的公司 ID，导致候选可选但保存失败。人员公司 ID 保留现有通讯录租户边界，不通过改员工资料解决业务公司差异。

- 责任确认沿用登记规则：未归档、在职、employee；只有 system_admin / asset_manager 可跨公司配置。
- 部门主管、组长和普通负责人的治理、改派及维护边界保持；跨公司配置继续由全局管理员维护。
- 人员选择器按同一规则筛选候选，说明责任确认后的本系统权限与外部平台权限边界。再次提交时清理旧消息。
- 选中人员使用行锁，与离职登记协调；保留资产归档、版本、部门校验、责任历史和审计。

修改文件：backend/app/api/v1/assets.py、frontend/src/pages/AssetDetailPage.vue、新增 backend/tests/test_asset_assignment_policy.py。
